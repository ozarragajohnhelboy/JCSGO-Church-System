# JCSGO Church Management System - PWA Implementation

## Paano Gamitin ang PWA

### Mobile Installation

#### Android

1. Buksan ang site sa Chrome
2. May lalabas na banner na "Install App"
3. Click "Install" o
4. Menu (3 dots) > "Add to Home Screen"
5. Icon lalabas sa home screen
6. Open app para sa fullscreen experience

#### iOS (iPhone/iPad)

1. Buksan ang site sa Safari
2. Click Share button (square with arrow)
3. Scroll down > "Add to Home Screen"
4. Edit name kung gusto
5. Click "Add"
6. Icon lalabas sa home screen

### Desktop Installation

#### Chrome/Edge

1. Buksan ang site
2. Look for install icon sa address bar (computer with arrow)
3. Click install icon
4. Click "Install" sa popup
5. App lalabas bilang standalone window

#### Shortcut

- Windows: Desktop shortcut automatic created
- Mac: App sa Applications folder

## Features

### Fast Loading

- Cached assets
- Instant page loads

## Uninstall

### Android

1. Long press app icon
2. Select "Uninstall" o "Remove"

### iOS

1. Long press app icon
2. Click "X" o "Remove App"
3. Confirm deletion

### Desktop

#### Chrome/Edge
1. Click 3 dots sa app window
2. "Uninstall [App Name]"

#### Windows
- Settings > Apps > Uninstall

#### Mac
- Drag from Applications to Trash

## Troubleshooting

### Hindi lumalabas ang install prompt

Solutions:
- Refresh ang page
- Clear browser cache
- Try incognito mode
- Check kung HTTPS

### Offline mode hindi gumagana

Solutions:
- Visit site at least once
- Wait for cache complete
- Check internet connection
- Reinstall app

### App hindi nag-uupdate

Solutions:
- Close app completely
- Clear cache
- Reinstall app
- Hard refresh (Ctrl+Shift+R)

## Support

For issues:
1. Check browser console errors
2. Clear site data
